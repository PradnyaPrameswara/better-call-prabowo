# Better Call Prabowo

An independent, clearly labeled **parody** website inspired by the retro-web layout of AMC's fictional *Better Call Saul* attorney site.

> This is an unofficial creative project. It is not affiliated with or endorsed by Prabowo Subianto, the Indonesian government, or AMC.

Development happens in reviewed feature branches. The initial work is split into a project foundation, a reference/asset inventory, and a shared visual shell.

Reference: https://bettercallsaul.amc.com/

See feature PRs for implementation.
